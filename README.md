# Iris Flower Classification

## Project Overview
This project is based on Iris Flower Classification using Machine Learning with Python. The main aim is to classify Iris flowers into three species: Setosa, Versicolor, and Virginica based on their measurements.

## Dataset
The dataset contains the following features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target variable: Species

## Technologies and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps
1. Loaded the Iris dataset.
2. Checked the dataset for missing values and duplicates.
3. Performed Exploratory Data Analysis (EDA).
4. Created visualizations to understand flower measurements.
5. Split the data into training and testing sets.
6. Trained a Machine Learning classification model.
7. Evaluated the model using accuracy, confusion matrix, and classification report.

## Model Performance
- Accuracy: 100%
- Test Samples: 30

## Conclusion
The model successfully classified the three Iris flower species on the test dataset. This project helped me understand the basics of Machine Learning, data preprocessing, visualization, and model evaluation.
